Quick-Connect Guide
  1. Open your FTP client (e.g. FileZilla)
  2. Set Host to {{ mainhost }}
  3. Enter your FTP Username and Password
  4. Set Port to 21
  5. Select Explicit FTP over TLS
  6. Click Quickconnect
Always use FTPS (TLS) — plain FTP sends passwords in clear text.
